# 垄上 · CKB 链上农场

一个完全跑在 [Nervos CKB](https://www.nervos.org/) 上的种菜、偷菜游戏。开垦、播种、除草除虫浇水、收获、卖菜、扩地、养狗，以及去邻居地里摘菜、帮忙、放草放虫，全部由一份链上合约验算。没有服务器，没有管理员，没有可升级的合约。

玩法是经典的社交农场那一类，但这是一个原创游戏：名字、美术、数值和界面都是这个项目自己的，没有使用任何现成游戏的素材。

## 一分钟跑起来

需要 Node 20+，以及 [offckb](https://github.com/ckb-devrel/offckb)（只用它下载的 `ckb` 节点程序；也可以用 `CKB_BIN=/path/to/ckb` 指定）。

```bash
./start.sh
```

它会依次：启动项目自带的本地链（`127.0.0.1:8214`）、部署合约、放出 4 个自己种地也会串门的邻居机器人、启动网页。然后打开 <http://localhost:5183>，右上角选一个测试账户，开垦农场。

本地链上 1 个游戏小时是 30 秒，萝卜 1 分钟就熟。

```bash
./start.sh stop
```

停掉本地链和机器人。`scripts/devnet.sh reset` 清空本地链重新开始。

## 为什么说它是去中心化的

| 通常由服务器做的事 | 这里怎么做 |
| --- | --- |
| 保存存档 | 每座农场是一个 CKB cell，状态（金币、经验、土地、仓库、每块地）就是 cell 的数据 |
| 判定操作是否合法 | 农场 cell 的 type script 重放交易里的操作列表，算出的新状态必须和交易输出逐字节相同 |
| 账号 | 农场记着主人的 lock hash。花金币的操作要求交易里有主人的 cell，也就是主人的签名 |
| 好友系统 | 没有。同一条链上的农场都是邻居，谁都可以去 |
| 计时 | 取自区块头的时间戳，见下文 |
| 随机（杂草、虫害、狗拦不拦） | 取自打包播种交易的那个区块的哈希 |
| 运营方关服、偷走 CKB | 做不到。农场 cell 的 lock 是公开脚本，能做的事只有规则允许的那几样，cell 里押的 CKB 只增不减 |
| 运营方改规则 | 可以，且公开：代码 cell 用 type id 固定身份、由部署者的锁看守。升级 = 部署者花一次代码 cell 换上新二进制，type id 不变，所有农场原地运行新规则（见下文"升级"）。改了什么、何时改的，链上全部可查 |

网页只是一个方便的客户端。它用的规则代码和合约是同一份 Rust（编译成 WASM），所以页面上显示的"可以做什么"和链上的判定不会不一致。任何人都可以另写一个客户端，或者直接构造交易。

### 一笔交易长什么样

```
inputs                          outputs
  [0] 我的农场  ──操作列表──▶    [0] 我的农场（新状态）
  [1] 邻居的农场 ─我的来访──▶    [1] 邻居的农场（新状态）
  [2] 我的普通 cell（付手续费，     [2] 找零
      同时证明我是 [0] 的主人）
header_deps: 两座农场各自所在的区块、一个最近的区块（证明"现在至少是几点"）
```

- 农场 cell 的 lock 也是这份合约，逻辑只有一条："这个 cell 必须带着农场 type script"。所以邻居不需要你的签名就能把你的农场放进交易，但能对它做的事只有规则允许的那几样（摘熟了的菜、帮忙、放草放虫），并且 cell 里押的 CKB 只增不减。
- 来访操作写在被访农场的 witness 里，指明访客是第几个输入。访客农场的脚本会重放同一份列表，把摘到的菜和帮忙的经验记到自己账上。两边各算各的，结果必须对得上。
- 一笔交易可以放很多操作。网页把你点的操作攒在篮子里，一次上链。

### 时间

合约没法知道"现在几点"，只能知道"某个区块存在，所以现在至少是它的时间"。因此：

- 交易带一个最近的区块头，它的时间戳就是这笔交易的"现在"。只能往早了报，报早了作物只会更不熟，没有好处。
- 播种时不记时间。下一次有人动这座农场时，合约读取"播种那笔交易所在区块"的时间戳和哈希，补记播种时刻并生成这块地的随机种子。播种的时间因此无法谎报。

## 规则

16 种作物，按等级解锁。时间单位是游戏小时：本地链 30 秒，默认部署 3600 秒（真实的一小时）。同一个时间单位的农场组成一个世界。

| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 白萝卜 | 1 | 80 | 2h | 1 | 16 | 10 | 6 |
| 胡萝卜 | 1 | 120 | 3h | 1 | 18 | 13 | 9 |
| 玉米 | 2 | 180 | 4h | 1 | 20 | 17 | 12 |
| 土豆 | 3 | 240 | 5h | 1 | 22 | 20 | 15 |
| 茄子 | 4 | 320 | 6h | 1 | 24 | 24 | 18 |
| 番茄 | 5 | 420 | 7h | 2 | 22 | 22 | 20 |
| 豌豆 | 6 | 500 | 8h | 1 | 26 | 34 | 26 |
| 辣椒 | 7 | 600 | 9h | 2 | 24 | 30 | 28 |
| 南瓜 | 8 | 760 | 10h | 1 | 28 | 48 | 34 |
| 草莓 | 10 | 900 | 11h | 2 | 26 | 40 | 38 |
| 西瓜 | 12 | 1150 | 12h | 1 | 30 | 68 | 44 |
| 葡萄 | 14 | 1400 | 14h | 3 | 26 | 52 | 48 |
| 香蕉 | 16 | 1800 | 16h | 2 | 30 | 75 | 56 |
| 菠萝 | 18 | 2300 | 18h | 1 | 34 | 130 | 66 |
| 桃 | 21 | 3000 | 20h | 3 | 30 | 110 | 76 |
| 樱桃 | 25 | 4200 | 24h | 2 | 36 | 190 | 96 |

- 起步 6 块地、500 金币，最多 18 块地。第 7 块地要 3 级和 2,000 金币，最后一块要 25 级和 280,000 金币。
- 升到第 n 级需要累计 `50 × n × (n − 1)` 点经验。
- 作物生长途中可能长草、生虫、缺水。收获时每留一样没处理，减产 10%。自己处理一次 2 点经验。
- 熟了的作物，每个邻居每季每块地能摘一次，每次摘走产量的 8%，所有邻居合计最多摘走 40%。
- 帮邻居处理一次问题得 3 点经验，每天前 50 次有效。每天最多使坏（放草或放虫）30 次。
- 3 级起可以花 300 金币喂狗，管一天（24 游戏小时）。狗站岗时，每个来访者在大约一半的地里会被拦下。
- 多季作物收完最后一季、单季作物收获后，会留下枯株，铲除得 3 点经验。
- 主人可以随时收回农场：cell 销毁，押着的约 332 CKB 回到钱包。

数值的唯一出处是 [crates/farm-core/src/crops.rs](crates/farm-core/src/crops.rs) 和 [crates/farm-core/src/lib.rs](crates/farm-core/src/lib.rs)。

## 目录

```
crates/farm-core   规则本身（no_std Rust）。合约和网页都编译这一份
contracts/farm     CKB 脚本：解析交易，调用 farm-core，核对输出
crates/farm-wasm   把 farm-core 包成 WASM 给网页用
tests              在 CKB-VM 里跑合约的测试（ckb-testtool）
web                网页客户端（React + CCC），以及部署、机器人、端到端脚本
devnet             项目自带本地链的配置
scripts            构建合约、构建 WASM、管理本地链
build/farm         编译好的合约（约 49 KB）
```

## 开发

```bash
cargo test -p farm-tests          # 29 个测试：规则 9 个，合约在 CKB-VM 里 20 个
scripts/build-contract.sh         # 需要 rustup target add riscv64imac-unknown-none-elf
scripts/build-wasm.sh             # 需要 rustup target add wasm32-unknown-unknown
```

```bash
cd web
npm run e2e                       # 在本地链上真实地玩一遍并核对链上状态（需要先 ./start.sh 或 scripts/devnet.sh start + npm run deploy:devnet）
npm run bots                      # 邻居机器人
npm run build                     # 类型检查并打包
```

改了规则就重新构建合约和 WASM，然后原地升级：`npm run build`（合约）→ `bash scripts/build-wasm.sh`（前端 WASM）→ `npm run upgrade`。升级花一次代码 cell 换上新二进制，**type id 不变**，所有农场原地运行新规则，不用重新开垦。规则改动的同步要点：合约与前端 WASM 是同一份 Rust，必须一起重编译，否则前端算出的初始状态会被链上拒绝（例如改了 `INIT_GOLD` 而没重编 WASM，开垦会报"新农场必须从初始状态开始"）。

### 测试网

合约部署在 CKB 测试网上，采用**可升级的两 cell 结构**：

- **type-id 校验器 cell**：锁是全零哈希（永远打不开），代码 cell 的 type script 就是它。它保证代码 cell 的 type id 只此一份、升级时不会漂移。
- **代码 cell**：锁是部署者的锁，data 是农场二进制。农场 cell 用 `hash_type: "type"` 引用代码 cell 的 type script 哈希，所以升级后所有农场原地运行新代码。

当前版本：代码 cell 交易 `0x2519aa27af73bc1534dd44c55095b3df531b2dcd410f7f944254736bc8dfef85`，引用哈希（code script hash）`0x0253fea2b3d45853c5381fb20ed7efffce8f79cfbb059e1ea3befddf299f775d`，游戏时速 3600 秒/小时。最新记录以 `web/src/chain/deployments.json` 为准。网页默认跑测试网；跑本地链则在 `web/.env` 里写 `VITE_NETWORK=devnet`。

测试网用 CCC 的钱包连接器登录：网页上是"连接钱包"按钮，支持 JoyID、MetaMask、OKX、UniSat 等。钱包需要有测试网 CKB（[水龙头](https://faucet.nervos.org/)）才能付手续费和创建农场 cell。本地链仍使用内置测试账户，不需要钱包。

代码 cell 约 49,000 CKB、校验器约 28,500 CKB。首次部署：

```bash
bash scripts/build-contract.sh
cd web
npx tsx scripts/deploy.ts --network testnet --privkey 0x你的私钥
```

**升级**（改了规则之后）：

```bash
bash scripts/build-contract.sh && bash scripts/build-wasm.sh
cd web && npx tsx scripts/upgrade.ts --network testnet --privkey 0x你的私钥
npm run build && npm run deploy:pages   # 前端记录更新后重新发布网页
```

注意信任模型：代码 cell 的锁就是升级权限，持有该私钥就能改写所有农场运行的规则（包括理论上影响农场内 CKB 的规则）。这个私钥等同于整个游戏的管理员密钥，请妥善保管。type-id 校验器保证升级只会"换代码"，不会意外改掉 type id，也没有人能伪造第二个代码 cell。

## 现状与已知限制

已验证的：

- 29 个 Rust 测试全部通过，合约测试跑在真实的 CKB-VM 里。
- 可升级部署在本地链上完整验证过：改 `INIT_GOLD` 500→600、升级、新农场拿到 600 金币、旧农场照常关闭收回 CKB，再升级回 500 同样生效；全程 type id 不变。
- `npm run e2e` 在本地节点上通过全部 13 步：开垦、陌生人不能花主人的金币、播种、未熟不能收也不能偷、邻居无需主人签名放草、处理、成熟、偷摘、不能重复偷、收获卖出、伪造状态被合约拒绝、主人收回农场。
- 网页在浏览器里实际走通了开垦、买种、播种、打理、收获、卖出、串门偷摘。
- 4 个机器人连续跑了一小时、四百多笔交易，没有失败。
- 测试网上用真实节点通过 `scripts/testnet-smoke.ts`：开垦、买种播种、收回农场并退回 CKB。钱包选择器在浏览器里正常打开（未用真实钱包私钥登录：本机没有这些钱包）。
- 测试网上完整的偷摘/收获流程需要 2 小时（萝卜 2 游戏小时 × 3600 秒），用 `FARM_NETWORK=testnet npm run e2e` 跑。

还没做的：

- **没有部署到主网。** 只有本地链和测试网。
- **没有用真实钱包私钥在浏览器里登录过。** CCC 钱包选择器已接好，但这里没有 JoyID、MetaMask 等钱包的私钥；测试网交易用私钥账号验证过。
- **合约没有经过审计。** 在放真钱之前请当它是实验品。
- 一座农场是一个 cell，同一个区块里只能被一笔交易动一次。两个人同时去同一家串门，后到的那笔会失败，需要重试。农场多了以后这不是问题，热门农场会比较挤。
- 随机数来自区块哈希。出块者理论上可以挑选对自己有利的哈希，对一个种菜游戏来说不值得，但它不是密码学意义上的公平随机。
- 网页通过节点的 RPC 列出所有农场，农场数量很大时需要分页或索引服务。
